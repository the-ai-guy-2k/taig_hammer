Finish the job and get out alive.

You are at a wrecked transport in the rust yards. The salvage is inside. A raider is watching the far side. The way out is a jammed hatch.

Your job: Search the wreck, bring the salvage back, get out alive. You win when salvage is found and you fix the jammed hatch and exit. You lose if your health runs out.

Side goals, not required to win: find useful supplies, keep health and gear in decent shape. Gear condition is tracked and shown, but it never causes a loss in v1.

How each action lands — exact

  • Search the wreck (+3, target 12): success = salvage found. Crit = salvage found + 1 supply. Fail = nothing. Crit fail = nothing, -2 health, gear -10%.
  • Sneak past the raider (+2, target 14): success = raider avoided. Crit = raider avoided + 1 supply. Fail = spotted, -5 health. Crit fail = spotted, -5 health, gear -10%.
  • Shoot the raider (+3, target 13): success = raider down. Crit = raider down + 1 supply, no damage. Fail = miss, -4 health. Crit fail = miss, -4 health, gear -10%.
  • Fix the jammed hatch and exit (+2, target 11): if salvage is not found, no roll — “You have not got the salvage yet. Search the wreck first.” Success or crit with salvage = win. Fail = hatch stays jammed, -2 health. Crit fail = hatch stays jammed, -2 health, gear -10%.
  • Use a supply (no roll): +5 health, up to 20, uses 1 supply. At 0 supplies: “No supplies left.”, nothing changes.

Crit = natural 20, crit fail = natural 1, before bonuses. Gear condition drops 10% on a crit fail, never below 0%, and never causes a loss in v1.

Install, launch, pause, close — how this game works

  • Installed: from GitHub only — clone or download the repo. No installer, no app store, no account, no spend.
  • Launched: open this file in a browser, one click. No server, no command line.
  • Interacted with: mouse / tap only. Pick an action, roll the d20, see skill vs target, health and supplies update on the board. No code typing, no CLI.
  • Paused: hit Pause — the turn freezes, action buttons lock, and state is saved locally. Hit Resume to continue exactly where you left off.
  • Closed: close the tab / window — progress stays saved locally in this browser. Reopen the same file to resume, no logout, no cloud save required.

Saved locally means: in this browser, on this device, for this file. A different browser or device will start a fresh run. If a browser blocks local storage for local files, the game still plays, but close/resume will not persist in that browser — that is a browser limit, not a different game design.
