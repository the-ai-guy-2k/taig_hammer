Original grimdark sci-fi game. Not affiliated with any other game company.

Single offline file, no server, no internet, no account, no AI rolls, no spend.

## Play it
Clone or download this repo, then open `hammer-game-dice-v1.html` in a browser.
No installer, no app store, no command line.

## The game
Solo. Search a wreck, bring the salvage back, get out alive.
Pick an action, d20 + skill vs target, see what you tried, roll, modifier, total, target, outcome, in order.

- Search the wreck: +3, target 12
- Sneak past the raider: +2, target 14
- Shoot the raider: +3, target 13
- Fix the jammed hatch and exit: +2, target 11, needs salvage first, no roll before salvage
- Use a supply: no roll, +5 health up to 20

Win: "Job done. You got out alive."
Lose: health out only, "Run over. Health out."
Gear drops 10% on a crit fail, never below 0%, never causes a loss in v1.
Natural 20 = crit success, natural 1 = crit fail, before modifiers.

Pause: hit Pause, the turn freezes and state saves locally.
Close: close the tab, reopen the same file to resume, no cloud save.
Play again resets exactly to Health 20/20, Supplies 3, Gear 100%, Salvage not found, Raider watching.
