Roll log

How each action lands — exact, same as dice v1

  • Search (+3, target 12): success = salvage found. Crit = salvage found + 1 supply. Fail = nothing. Crit fail = nothing, -2 health, gear -10%.
  • Sneak (+2, target 14): success = raider avoided. Crit = raider avoided + 1 supply. Fail = spotted, -5 health. Crit fail = spotted, -5 health, gear -10%.
  • Shoot (+3, target 13): success = raider down. Crit = raider down + 1 supply, no damage. Fail = miss, -4 health. Crit fail = miss, -4 health, gear -10%.
  • Fix (+2, target 11): if salvage is not found, no roll — “You have not got the salvage yet. Search the wreck first.” Success or crit with salvage = win. Fail = hatch stays jammed, -2 health. Crit fail = hatch stays jammed, -2 health, gear -10%.
  • Use a supply (no roll): +5 health, up to 20, uses 1 supply. At 0 supplies: “No supplies left.”, nothing changes.

Crit = natural 20, crit fail = natural 1, before bonuses. Gear drops 10% on a crit fail, never below 0%, and never causes a loss in v1. Animation does not change any number. The numbers are the game.
